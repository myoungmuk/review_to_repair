Google Docs upload workaround

Why this folder exists:
- Your original DOCX upload may not offer the normal Google Docs conversion path.
- HTML and TXT are safer fallback formats for Drive-to-Docs conversion.

Latest recommended files:
- `kcc_v9_for_gdocs.html`
- `kcc_v9_for_gdocs.txt`
- `kcc_v9_for_gdocs.rtf`

Older reference files:
- `kcc_v8_for_gdocs.html`
- `kcc_v8_for_gdocs.txt`
- `kcc_v8_for_gdocs.rtf`

Recommended order:
1. Upload `kcc_v9_for_gdocs.html`
2. Open it with Google Docs or let Drive convert it
3. If HTML feels awkward, upload `kcc_v9_for_gdocs.txt`
4. If needed, try `kcc_v9_for_gdocs.rtf` as an alternate import path

Practical note:
- HTML should preserve structure better
- TXT is the safest fallback
- RTF is useful if Docs handles HTML awkwardly on a given upload
